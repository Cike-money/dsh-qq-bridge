# v0.1.1

这一版补上了「装上就能配、配完自己连」的体验。

- **配置页**：插件自带浏览器半侧，在插件页的组合包卡片里直接出表单，29 个字段都能填能改；保存走宿主的配置服务，失败会保留你填的值。
- **NapCat 引导**：配置页顶部提示「还没装 NapCat？」并给出官网入口；装好留空 `napcatDir`，插件会自己去常见位置找。
- **自动对齐**：连不上时读 NapCat 自己的 onebot 配置，按它实际开的端口和口令对齐（不改它的文件）。
- **自动拉起**：NapCat 没开就顺手拉起来，日志提示去窗口扫码，登录完桥自动连上。
- **token 可选**：NapCat 没设口令就留空，带不带 `Bearer` 由配置决定。
- **门铃**：默认关；开了的话端口 `0` = 随机空闲端口，口令空着随机生成。
- **修的问题**：端口被占用不再把宿主带崩；缺会话服务时立刻报错而不是干等十分钟；静默词可以配空关掉；群表七天清理；配置页保存异常不再卡在「保存中」。

默认值里没有真实 QQ 号、token、盘符；NapCat 地址用出厂默认的 `127.0.0.1:3000 / 3001`。

已知限制：只在 Windows 验证过；依赖 DSH 0.2.1-rc.2 的会话服务；同一 NapCat 只接一个桥。
